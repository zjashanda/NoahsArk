## 3. 关键路径与并行泳道

### 3.1 唯一关键路径（建议冻结版）

`DG0 -> DG1 -> DG2 -> DG3 -> DG4 -> W0 -> W1 -> W2 -> W3 -> W4 -> W6 -> W7 -> W8 -> W9 -> DG9 -> W10 -> DG10`

说明：

1. 该路径采用施工方案 §5.1，把 W8 计入关键路径，因为 TCL 是 P6-03/P6-04 的前置。
2. `phase5-implementation-plan.md` §6.2 写作 `W0 -> ... -> W7 -> W9 -> W10` 并把 W8 列为并行。两份文档不一致，必须在 P3-07 前择一，详见 §5 缺口 G5。
