## 4. 状态覆盖

设计规范覆盖 loading / empty / error / blocked / stale / disabled 六类状态；原型演示情况：

| 状态 | 设计 | 原型 | 说明 |
|---|---|---|---|
| loading | 每页有骨架/文字进度 | 部分 | 原型默认同步渲染，未提供可触发的慢加载 |
| empty | 每页有文案 + 出口 | 部分 | 任务筛选空态、知识无结果、队列空态可触发 |
| error | 影响 + 重试 + 请求 ID | 未演示 | 需要 API fixture 才能模拟；设计已定义 |
| blocked | 朱砂横幅 + 解除条件 | 有 | 0412 待批准、0399 C4 分歧、工具链漂移 |
| stale | 墨灰 + 虚线 + 最后更新 | 有 | 知识 kb-1029、节点 linux-01、工具链冒烟过期说明 |
| disabled | 原因 + 权限 | 部分 | 审批/接管按状态禁用；固定角色 3，未做角色切换演示 |

诚实说明：原型不能替代状态回归。实现阶段需要为每页准备六类 fixture 与视觉快照。

## 5. 可访问性评审

### 5.1 已达到

- 文本对比度：`#1B2A2E` / `#F4F0E6` 13.0:1；`#43585B` 6.6:1；`#5E7072` 5.0:1（卡片）；`#FCFAF4` / `#1F5F5B` 7.1:1；朱砂文本 `#8E3320` 7.0:1。
- 焦点：`:focus-visible` 2px `#1F5F5B` + 2px offset；无 `outline:none` 无替代。
- 键盘：Tab 顺序、Esc 关闭弹层、Ctrl/Cmd+K 命令面板、门禁印章 Enter 触发、接管输入可聚焦。
- 语义：`header/nav/main/aside`、`role=tablist/tab`、`role=switch`、`role=alert`、`aria-live=polite`、按钮 `aria-label`。
- 状态不只靠颜色：门禁有勾/叉/暂停/斜纹；知识状态有文字；漂移有文字。
- 减少动态：`prefers-reduced-motion` 下禁用位移、脉冲与扫光。
- 跳过链接：`跳到主内容`。
- 触控：按钮高度 26 至 34，手机主操作由 44px 容器包裹；设计令牌要求 44，实现阶段需逐项核对。

### 5.2 未完成/需实现阶段验证

- **未运行屏幕阅读器实测**（NVDA + Edge/Chrome）。语义结构已写，但没有真人走查。
- **未运行 axe-core 自动化**。原型无构建依赖；实现阶段应加入本地 axe。
- **页签/门禁方向键**：原型已支持页签左右方向键与门禁印章左右方向键、Enter 触发；仍需屏幕阅读器实测确认播报。
- **接管终端文本替代**：设计定义了“文本日志”页签，原型只有终端 DOM，没有独立文本视图。
- **高对比度模式**：未在 Windows 高对比度下验证。
- **200% 缩放**：布局策略已定义，未做截图回归。
- **44px 触控目标**：部分小按钮 22 至 26px，桌面可接受，手机需扩大点击区。
- **表单错误关联**：设计写了 `aria-describedby`，原型未逐字段演示。

结论：可访问性设计为 **AA 目标 + 部分实现**，不能声称已通过 WCAG AA 审计。

## 7. 已知缺口（按优先级）

### P0（进入实现前必须解决）

1. **API 契约映射**：页面字段依据计划与契约推导；API 冻结后需逐页核对枚举、错误码、分页、权限。
2. **六类状态 fixture**：loading / empty / error / blocked / stale / disabled 的每页快照与回归。
3. **真实 xterm**：原型终端是 DOM mock；实现必须本地打包 xterm，处理回放、重连、只读、脱敏。
4. **SSE 降级**：原型“实时/降级/离线”是手动切换；实现需 `Last-Event-ID`、5s 轮询、去重、可见降级。
5. **角色与权限**：原型固定角色 3；实现需按 1 至 4 控制按钮、路由与服务端校验。
6. **可访问性实测**：NVDA/Edge、axe、200% 缩放、高对比度、触控目标。

### P1（影响设计完整性）

7. **任务详情数据复用**：0412 的详情最完整；其他任务共用部分计划/评审/日志文案。实现阶段应按 task_id 投影真实数据。
8. **知识详情正文**：所有 kb_id 共用同一套“适用条件/步骤/反例”结构；实现阶段按条目渲染。
9. **表格排序/列设置**：设计提到排序与筛选，原型只实现筛选，未实现列排序。
10. **移动端 390 实体测试**：CDP 模拟通过；iOS Safari 地址栏、safe-area、软键盘仍需真机。
11. **长页面**：390 下模型页约 5300px、Agent 页约 3800px；建议实现阶段加入分区折叠或锚点导航。
12. **图标最终集**：原型为简化内联 SVG；需统一为本地图标集并核对 1.5px 风格。

### P2（后续增强）

13. **全局深色主题/打印**：本期浅色为唯一全局主题，终端局部深色；交付报告由独立 HTML 报告承担。
14. **C8 测试有效性**：P4-12 未定义；UI 预留位置但不显示未定义通过状态。
15. **多语言**：中文为主；英文眉标与术语保留；未做 i18n 框架。
16. **引导与帮助**：无首次使用引导；依赖空状态与文案解释。
17. **数据可视化**：总览使用阶段分布与门禁印列，没有趋势图；趋势需要真实时间序列后再设计。

## 10. 评审结论

**设计侧结论：可以进入用户评审。** 视觉方向、IA、页面规格、状态矩阵、共享组件与流程完整；原型可点击、可演示、明确标注 mock，并且不引用任何既有平台 UI。

**不能声称的：**
