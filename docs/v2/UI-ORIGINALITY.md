# NoahsArk UI 原创性记录 v1.0

> 适用范围：`noahsark/docs/v2`、`noahsark/design`、`noahsark/assets`。
> 结论：NoahsArk Console 的视觉身份、外壳、令牌、组件形态、线框与原型均从第一性原理重建；**没有复用 legacy 平台的 UI、模板、静态资源、页面结构或设计令牌**。
> 本文只记录设计交付；不包含产品/后端实现。

---

## 1. 有意不复用的内容

以下内容全部来自 legacy 平台，NoahsArk 明确不继承。为避免在交付物中继续传播旧名称，本文统一使用“legacy 平台”指代。

### 1.1 外壳与导航

| 不复用项 | legacy 平台做法 | NoahsArk 做法 |
|---|---|---|
| 应用外壳 | 固定左侧导航栏 + 顶栏 + 内容区 | 顶部 26px 状态缎带 + 90px 双行命令甲板 + 单一滚动主区；桌面无常驻左侧导航 |
| 导航形态 | 分组侧栏、图标 + 标签、可收起 72px 图标轨 | 11 个横向编号入口（01 至 11），当前项用海青下划线，不用填充胶囊或左侧色条 |
| 移动导航 | 侧栏抽屉 + 底部 5 入口 | 顶部整高 sheet + 底部 5 入口；接管页全屏 |
| 页面上下文 | 顶栏面包屑 | 详情页 36px 上下文条，列表页不占位 |

### 1.2 颜色、材质与令牌

| 不复用项 | legacy 平台做法 | NoahsArk 做法 |
|---|---|---|
| 全局主题 | 深色驾驶舱，黑蓝底 | 浅色航次档案纸 `#F4F0E6`；终端/接管局部深墨绿 `#12211F` |
| 主色 | 高饱和蓝 | 海青 `#1F5F5B` |
| 人类信号 | 琥珀色 | 朱砂 `#B8482C`，唯一人类色 |
| 证据色 | 亮青绿 | 海玻璃绿 `#2C7A6B` |
| 材质 | 玻璃拟态、发光、柔光投影 | 哑光纸面、1px 墨线、2px 偏移印刷阴影 |
| 卡片圆角 | 12px 以上大圆角 | 4px 档案卡圆角 |
| 旧别名 | 保留旧 `--bg` / `--surface` / `--brand` 映射 | 不保留任何旧别名；只使用 `--na-*` 语义 token |

### 1.3 字体、密度与动效

| 不复用项 | legacy 平台做法 | NoahsArk 做法 |
|---|---|---|
| 展示体 | 无衬线 / 工业展示体 | Sitka Banner 档案体，仅用于品牌字、页面标题、关键数字 |
| 正文 | 系统无衬线 | Aptos / Segoe UI / 微软雅黑 |
| 等宽 | 终端等宽 | Cascadia Mono / Consolas，承载 ID、哈希、版本、日志 |
| 密度 | 深色高密度终端感 | 纸面编辑密度：13px UI 正文、40 至 44px 表格行、44px 区块间距 |
| 动效 | 扫光、脉冲、发光过渡 | 纸页进入 3px 位移、下划线生长、按钮按压缩放；减少动态时全部静止 |

### 1.4 页面结构与文案

| 不复用项 | legacy 平台做法 | NoahsArk 做法 |
|---|---|---|
| 总览 | 驾驶舱式 hero + 三张同构功能卡 + 事件磁带 | 航次卷首 + 决断页边 + 2:1 异常账页/信号栈 + 横向节点带 |
| 任务详情 | 侧栏 + 顶栏 + 右侧上下文卡 | 上下文条 + 档案体任务头 + 门禁印列 + 11 个 folio 页签 + 右侧 folio |
| 门禁 | 连续进度或圆点梯 | 7 枚离散方角门禁印列，二进制状态，不压成百分比 |
| 进度 | 航程条 | 潮位尺：3px 刻度线 + 7 个阶段刻度 + 当前指针 |
| 事件 | 事件磁带 | 信号栈中的事件条带，按时间线读取 |
| 空状态 | 通用插画 | ark 节点链线稿 + 未点亮门禁印 + 页边批注位 |

### 1.5 品牌与资源

| 不复用项 | legacy 平台做法 | NoahsArk 做法 |
|---|---|---|
| Logo | 旧船体 + 三角索具 + 暖色节点 | 五节点船体链 + 甲板 + 桅杆 + 两条张索 + 单一朱砂信号节点；重新绘制 |
| 图标 | 旧图标集 | 本地内联 SVG，1.5px 自绘路径 |
| 图片/字体 | 可能依赖外部资源 | 零 CDN、零外部字体、零外部图片；全部本地或系统字体 |
| 代码/模板 | 旧模板与静态模块 | 只有设计文件；原型是单文件本地 HTML/CSS/JS，不导入任何旧模块 |

## 2. 保留的只是平台功能，不是表达

以下能力是 NoahsArk 产品需求，必须保留；它们以全新视觉与交互表达重建：

- 页面：总览、任务、任务详情、知识、节点/设备、模型、版本/工具链、推送、Agent、讨论/圆桌、接管、系统。
- 状态矩阵：loading / empty / error / blocked / stale / disabled，以及任务、知识、连接状态。
- 组件：进度、门禁、卡片、表格、终端、模型切换、版本漂移、活动推送、接管。
- 可访问性：键盘、焦点环、语义结构、减少动态、200% 缩放、44px 触控目标策略。
- 响应式：1440 / 1024 / 390 三档；表格转卡片；接管全屏。

保留功能不等于复用表达：所有页面布局、组件形态、颜色、字体、文案语气和交互反馈均由本项目的 `UI-DESIGN.md` 与 `design-tokens.json` 定义。

等价的白名单校验（PowerShell，逐文件统计）：

```powershell
$pat = 'z[h]sh|O[r]ion|v14[-]workspace|o[r]ion[-]synapse-ui-design-brief|CONTROL[ ]ROOM'
$files = Get-ChildItem -Recurse -File noahsark/docs/v2,noahsark/design,noahsark/assets |
  Where-Object { $_.Extension -in '.md','.json','.html','.svg','.css','.js' }
$total = 0
foreach ($f in $files) {
  $m = Select-String -Path $f.FullName -Pattern $pat -AllMatches -CaseSensitive:$false
  if ($m) { $total += ($m | ForEach-Object { $_.Matches.Count } | Measure-Object -Sum).Sum }
}
"files=$($files.Count) hits=$total"
```

结果：

```text
files=26 hits=0
```

说明：

- 审计模式使用字符类（例如 `z[h]sh`）书写，保证审计文档本身不会被同一模式命中；实际语义与逐词审计一致。
- 审计覆盖设计文档、令牌、线框、原型、Logo 以及 `UI-REVIEW.md`。
- 旧平台的名称、路径、UI brief 与 shell 标签均未出现在交付物中。

## 6. 已知边界

1. 本文只证明“设计交付未复用 legacy 平台 UI”，不证明产品代码已经实现或已经通过真实 API 验证。
2. 原型中的交互为 mock；真实 SSE、xterm、权限与命令门面需在实现阶段接入。
3. 视觉验证通过 CDP 计算样式、几何矩形、溢出检测与路由文本检查完成；人工视觉复核仍待用户评审。
4. 旧平台的“功能清单”可以作为需求来源，但其页面结构、令牌、组件形态与文案不得进入 NoahsArk 实现。
