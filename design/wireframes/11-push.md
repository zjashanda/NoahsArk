# 11 · 推送 Push

- 路由：`/aitest/push`
- 目标：让任务事件可靠到达终端、文件、Webhook；失败可见、可重试。
- 权限：1 至 4 可读；个人订阅 2 至 4；全局/删除 4。
- 能力：订阅 CRUD、通道、过滤、测试、投递账本、死信。

## 状态

```
加载：    指标/表格骨架
空：      “还没有推送订阅” + [创建 CLI 订阅] / [创建 Webhook]
错误：    推送延迟：顶部“任务状态不受影响”；订阅仍可编辑
阻塞：    allowlist 拒绝/密钥缺失：行内红“配置错误”；测试失败
陈旧：    投递数据 >60s：灰“最后更新”；不显示实时
禁用：    角色 1 新建/编辑；非 4 全局/删除
```

## 边界

- 永不显示 webhook secret；只显示 cred ref。
- push.test 不得写成 task.completed。
- 推送失败不改变任务状态。
- 死信重试不绕过签名/allowlist。
