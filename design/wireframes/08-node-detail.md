# 08 · 节点详情 Node Detail

- 路由：`/aitest/nodes/<node_id>`
- 目标：诊断单台节点是否可执行、设备是否可用、最近发生了什么。
- 权限：1 至 4 可读；节点任务 2 至 4；释放租约/重装 Agent 4。
- 能力：心跳、CLI、设备、租约、节点任务窗口。

## 区块

1. 节点头：名称、状态、OS、IP、Agent 版本、心跳、当前任务。
2. 运行状态：CPU/内存/磁盘细条；无数据“未采集”，不显示 0%。
3. 版本表：已安装/锁定/兼容/漂移；跳工具链。
4. 设备表：设备、固件、串口、音频、项目、租约、状态。
5. 租约历史：lease、任务、获取/释放、结果、冲突。
6. 节点任务窗口：受控模板 + 输出时间线 + 审计提示。
7. 最近任务：5 条。

## 状态

```
加载：    节点头 + 区块骨架
空：      “尚未登记设备” + [粘贴设备文本]
错误：    Agent 失联：氧化红横幅 + 最后心跳；节点任务禁用
阻塞：    租约被占用：显示持有任务/控制者；释放需角色 4
陈旧：    指标 >60s：灰 + “最后采集 14:19”；不显示实时
禁用：    角色 1 节点任务/释放/重装
```

## 边界

- 节点任务不是任意 shell；仅注册模板与只读诊断。
- 重装 Agent 会中断当前租约，必须说明。
- 不显示 Agent 密钥/注册 token。
