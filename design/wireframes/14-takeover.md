# 14 · 接管 Takeover

- 路由：`/aitest/tasks/<task_id>/takeover`
- 目标：安全观察或接管执行会话，回放历史、注入输入、释放控制。
- 权限：2 观察；3 交互自己；4 任意；终态不可接管。
- 能力：session registry、lease CAS、safe pause、replay、input、release。

## 边界

- 接管不是 raw shell。
- 不显示凭据、provider key、tool 敏感参数。
- 释放后从 checkpoint 恢复；重复 effect 被拒绝。
- 断线不改变任务状态；输入禁用。
