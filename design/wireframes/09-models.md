## 状态

```
加载：    全局卡骨架；表格 5 行；有效绑定“解析中”
空：      “尚未同步模型目录” + [同步目录]（4）；禁止新建绑定
错误：    目录不可用：保留上次快照并标 stale；切换禁用
阻塞：    MODEL_BLOCKED / 配额用尽：氧化红横幅 + 受影响对象
陈旧：    catalog 超 TTL：赭石“快照已过期，不可用于新绑定”
禁用：    角色不足；能力不满足；stale 模型；compiled_fallback 不可伪装
```

## 边界

- 不显示 provider key / base URL / 原始响应。
- 切换不等于立即中断；必须写“下一轮生效”。
- 少于两个健康家族 → PANEL_DEGRADED，圆桌不得宣称多模型。
- 409 revision 冲突不覆盖，刷新后重选。
