## 正文结构

```
摘要
适用条件（项目/设备/固件/pin/scope/前置）
操作步骤（编号，可复制）
失败模式与反例（至少一条或“暂无已知反例”）
证据与引用（指针 + 哈希 + 来源任务）
修订说明（本版改了什么）
```

## 治理动作

| 动作 | 角色 | 必填 | 结果 |
|---|---|---|---|
| 应用到计划 | 3 至 4 | 目标任务 | 创建草案修订，审计 |
| 反馈 | 2 至 4 | 类型 + 备注 | kb_feedback |
| 佐证 | 4 | 独立证据 | corroborated |
| 批准 | 4 | review receipt + 适用范围 | approved |
| 标记争议 | 3 至 4 | 理由 + 反例 | disputed |
| 标记陈旧 | 4 | 新 pin/版本/反例 | stale |
| 撤回 | 4 | 理由 | retracted，保留修订 |
| 合并 | 4 | 目标条目 + 对比 | 新修订，旧条目指向新 |

## 状态

```
加载：    标题 + 正文骨架；右栏骨架
404：     “知识条目不存在或已撤回” [返回搜索]
错误：    保留标题/状态；正文错误卡 + 重试 + rev
阻塞：    disputed/stale 横幅说明原因与影响；仍可读
陈旧：    顶部“基于旧 pin”；适用性“当前不匹配”
禁用：    非 4 的提升/撤回/合并；无权限应用
```

## 边界

- 不在正文嵌入未脱敏日志。
- “已批准”不等于永久正确；stale/disputed 必须显式。
- 修订不可变；编辑生成新修订。
- 引用可点击回到来源任务/证据；失效引用显示“来源已归档”。
