# NoahsArk UI 线框索引 v2.0

> 设计交付物，非实现。所有界面为 ASCII 结构示意，真实视觉以 `design/ui-prototype.html` 与 `docs/v2/UI-DESIGN.md` 为准。
> 基准：桌面 1440 × 900；平板 1024 × 768；手机 390 × 844。线框只表达信息层级、区域与状态，不表达最终像素。
> 身份：**航次档案（Voyage Ledger）**。浅色档案纸、深墨绿文字、海青航向、朱砂人类批注、海玻璃绿证据。

## 视觉基线

| 项 | 决策 |
|---|---|
| 画布 | `#F4F0E6` 暖白档案纸，3% 横向纸纹 |
| 卡片 | `#FCFAF4`，1px 墨线，4px 圆角，2px 偏移印刷阴影 |
| 文字 | `#1B2A2E` 主 / `#43585B` 次 / `#5E7072` 元数据 |
| 航向色 | 海青 `#1F5F5B` |
| 人类色 | 朱砂 `#B8482C`，只用于等待、审批、接管、人工阻塞 |
| 证据色 | 海玻璃绿 `#2C7A6B` |
| 终端 | `#12211F` 深墨绿台面 + `#E7E3D6` 文本 |
| 展示体 | Sitka Banner / 档案体，用于页面标题与关键数字 |
| 正文 | Aptos / Segoe UI / 微软雅黑 |
| 等宽 | Cascadia Mono / Consolas |

## 通用状态

| 状态 | 线框表现 |
|---|---|
| loading | 结构骨架，保留标题与操作位置；超过 1s 出现文字进度 |
| empty | 线稿 + 标题 + 解释 + 主动作 |
| error | 页内错误卡或顶部横幅；影响 + 重试 + 请求 ID |
| blocked | 朱砂横幅；阻塞原因 + 解除条件 + 责任人 |
| stale | 墨灰 + 虚线；最后更新时间 + 刷新 |
| disabled | 降低透明度 + 原因；不使用仅颜色变化 |
| degraded | 命令栏赭石“降级轮询 · 5s”；页面顶部 1px 赭石线 |
