# 07 · 节点与设备 Nodes & Devices

- 路由：`/aitest/nodes`
- 目标：看清哪些机器在线、哪些设备可用、租约被谁持有。
- 权限：1 至 4 可读；节点任务 2 至 4；注册/释放租约 4。
- 能力：节点心跳、OS、CLI 版本、设备、串口、音频端点、项目、租约。

## 租约规则

- 租约显示：`lease-9f2 · ait-20261026-0412 · 到期 14:55`。
- 被占用：氧化红“被占用”，hover 显示持有任务与控制者。
- 角色 4 可释放，需确认并说明影响任务；普通用户无“强制抢占”。

## 状态

```
加载：    4 张节点卡骨架；设备表 5 行骨架
空：      无节点“还没有节点” + [注册第一台节点] / 部署文档
错误：    心跳服务不可用：顶部“节点状态可能滞后”；保留上次数据
阻塞：    失联/租约冲突：卡上赭石/氧化红点 + 原因；相关任务“等待设备”
陈旧：    心跳 >90s：灰 + “最后心跳 3 分钟前”；不显示在线
禁用：    角色 1 节点任务/注册/释放；失联节点的任务
```

## 边界

- 不显示 SSH 密码、私钥、provider key；只显示 credential_ref 是否存在。
- 在线必须有最近心跳，不能用缓存伪装。
- 文本解析失败行标红并说明，不静默丢弃。
- 节点任务不是任意 shell，只提供受控模板。
