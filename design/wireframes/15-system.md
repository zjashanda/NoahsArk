# 15 · 系统设置 System / Settings

- 路由：`/aitest/system`
- 目标：管理功能开关、角色、安全、审计、存储，让“平台为什么这样表现”可解释。
- 权限：角色 4；1 至 3 只读且隐藏敏感值。

## 关闭 V2 确认

```
┌──────────────────────────────────────────────┐
│ 关闭 V2 能力                          [关闭] │
│ 将隐藏 v2 页面并禁用相关写操作。              │
│ 不会删除任务、证据、知识或事件。              │
│ 当前运行中的任务不会被终止。                  │
│ 输入 DISABLE V2 确认： [···················] │
│ [取消]                    <关闭 V2>          │
└──────────────────────────────────────────────┘
```

## 状态

```
加载：    分组骨架；开关“读取中”
空：      审计为空“还没有审计记录”；不隐藏分组
错误：    设置读取失败：红横幅；保存禁用；请求 ID
阻塞：    维护/只读：顶部横幅；所有写开关禁用
陈旧：    设置缓存 >30s：灰“最后读取”；保存前强制刷新
禁用：    非 4 全部写；最后管理员移除；未知开关值
```

## 边界

- 不显示 secret、token、密码、完整 DB 路径。
- 开关默认关闭、未知值关闭；不提供“猜测开启”。
- 关闭能力不删除数据。
- 最后一个超级管理员不可降级；提前禁用并解释。
