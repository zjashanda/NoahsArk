- 路由：`/aitest/tasks`
- 目标：快速找到“需要我处理”的任务，并判断它的阶段、结论与可信度。

## 列定义

| 列 | 内容 | 规则 |
|---|---|---|
| 任务 | 标题 2 行 + ID + 风险 A/B | 标题截断；ID 等宽可复制 |
| 项目·设备 | 项目 + 设备 | 无设备显示“未分配” |
| 阶段 | 迷你潮位尺 + 百分比 + 当前阶段 | 百分比只描述阶段 |
| 门禁 | 7 个 8px 方块 | 失败优先；hover 显示缺失项 |
| 结论 | 状态徽章 | 未评估显示“未评估”，不能绿色 |
| 证据 | 文件数 + 大小 | 0 显示“0” |
| 模型 | G/A/T + 短名 | hover 完整 binding |
| 更新 | 相对时间 | <24h 相对，否则日期 |

## 状态

```
加载：    表头保留；8 行骨架；筛选可用；结果区“正在加载任务投影”
空：      保留表头与筛选；“没有匹配的任务” + [清除筛选] / [从需求开始]
错误：    顶部横幅“任务列表加载失败” + 重试 + 请求 ID；保留上次缓存
阻塞：    行内“人工阻塞” + 极轻朱砂底；不整表染色
陈旧：    右上“最后更新 14:18”；超过 60s 时间列加“可能滞后”
禁用：    角色 1 新建禁用；不可执行菜单项隐藏/禁用并解释
```

## 边界

- 不做批量批准/批量停止；批量仅导出。
- 不显示需求全文；不显示密钥。
- `dry_run` 任务显示“预演”，不进入通过统计。
- 筛选写入 URL，返回保留筛选与滚动位置。
